# No Andar de Cima

No Andar de Cima é um jogo eletrônico de narrativa interativa, onde o jogador assume o papel de um novo morador de um prédio antigo. Logo após a mudança, ele começa a ouvir sons estranhos vindos do apartamento de cima e resolve investigar. </br>
Ao longo da narrativa, o jogador deve fazer escolhas que o guiarão a descobrir, ou não, o que realmente aconteceu no andar de cima.
A atmosfera do jogo se desenvolve por meio de uma narrativa envolvente e misteriosa, com diferentes ramificações baseadas nas decisões do jogador.

## Origem do projeto

*No Andar de Cima* nasceu como **projeto de faculdade**, quando a primeira versão foi desenvolvida em **Lua com o framework LÖVE (love2d)**.

Desde então, venho estudando desenvolvimento de jogos por conta própria para criar uma **nova versão com maior qualidade** — reescrita do zero para rodar no navegador, com história expandida, interface repensada, arte e trilha sonora próprias. Este repositório acompanha esse processo.
